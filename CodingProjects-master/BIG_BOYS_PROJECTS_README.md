# Big Boys Projects System

Система оценки масштабных проектов школьников с использованием нейросети.

## Функционал

1. **Отправка проектов**: Школьники отправляют код проекта и текстовую защиту
2. **Оценка нейросетью**: Оценивается и код, и защита проекта
3. **Блокировки**: Маленькие проекты (<500 символов) блокируют доступ до конца дня
4. **Разблокировка**: Можно разблокировать доступ за 50 монеток
5. **Детекция ИИ**: Обнаружение кода, сгенерированного ИИ (уменьшение баллов)
6. **Награды**: Монетки и опыт за одобренные проекты
7. **Комментарии**: Комментарии к коду с указанием ИИ-частей

## Установка

1. Запустите миграции и сидер:
```bash
php artisan projects:setup
```

2. Доступ к системе: `/insider/projects`

## Структура базы данных

- `big_boys_projects` - проекты
- `project_comments` - комментарии к коду
- `user_project_blocks` - блокировки пользователей
- `project_evaluations` - результаты оценки

## Логика оценки

1. **Минимальный размер кода**: 500 символов
2. **Оценка кода**: 70% от общей оценки
3. **Оценка защиты**: 30% от общей оценки
4. **Порог одобрения**: 30/100 баллов
5. **Блокировка**: <10 баллов
6. **Награды**: Зависят от сложности и оценки

## API сервиса оценки

Сервис `ProjectEvaluationService` содержит методы:
- `evaluateCodeQuality()` - оценка качества кода
- `evaluateDefenseText()` - оценка текста защиты
- `detectAIContent()` - детекция ИИ-кода
- `calculateComplexity()` - расчет сложности

## Интеграция с нейросетью

Для реальной интеграции с нейросетью:
1. Замените методы в `ProjectEvaluationService`
2. Добавьте API вызовы к нейросети
3. Настройте обработку ответов

## Тестовые данные

Сидер создает тестовые проекты для демонстрации:
- Умный калькулятор на Python
- Система управления задачами на Flask
